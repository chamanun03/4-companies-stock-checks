Tech Stock Info Board

A simple interactive web page that displays information about leading technology companies 
and links to their real-time stock data.

Overview

This project was built to practice front-end web development using vanilla HTML, CSS, 
and JavaScript. Users can click on each company card to view a brief description and 
navigate to live stock charts via TradingView.

Companies Covered

- Amazon (AMZN)
- Microsoft (MSFT)
- Google / Alphabet (GOOGL)
- Meta (META)

Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

Features

- Responsive card layout
- Click-to-open overlay with company details
- Direct link to real-time stock charts on TradingView
